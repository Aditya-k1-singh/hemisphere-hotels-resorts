# Hemisphere Hotels & Resorts - UI Build

This repository contains the front-end digital ecosystem for Hemisphere Hotels & Resorts, encompassing the central Brand Portal and a scalable Property Template.

## Tech Stack
- HTML5 / CSS3 (Vanilla, CSS Custom Properties for theming)
- JavaScript (ES6+ Modules, Web Components)
- Three.js (WebGL enhancements for hero/map)
- Node.js (Only used for the lightweight build script `build.js`)

## Getting Started

1. **Build the site** (injects header/footer partials into HTML pages):
   ```bash
   node build.js
   ```
2. **Serve locally**:
   Use any local static server. For example:
   ```bash
   npx serve .
   ```
   Or using Python:
   ```bash
   python -m http.server
   ```

## Creating a New Property

The architecture is designed for easy replication (e.g., adding Damai Beach Resort):

1. **Duplicate a Property Folder**:
   Copy the `grandmargherita/` folder and rename it (e.g., `damaibeachresort/`).
2. **Create Data Source**:
   Copy `data/properties/grandmargherita.json` to `data/properties/damaibeachresort.json` and update the content.
3. **Update Tokens & Markup**:
   In `damaibeachresort/index.html`:
   - Change `--prop-accent` to the property's assigned color token (e.g., `#3E6E73` for Damai Beach).
   - Update the booking widget tag: `<hemi-booking-widget property="damaibeachresort"></hemi-booking-widget>`
   - Update text/images according to the JSON data.
4. **Rebuild**:
   Run `node build.js` to ensure partials are injected.
